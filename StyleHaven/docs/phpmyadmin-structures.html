How to produce the required phpMyAdmin screenshot
  1. Start Apache and MySQL in the XAMPP control panel.
  2. Open http://localhost/phpmyadmin and import database/stylehaven.sql.
  3. Click the stylehaven_db database in the left column, then open the Structure tab of any table below.
  4. Screenshot the table structure (or the database's table list) and paste it into the documentation.

This page is generated from that same SQL file by tests/build-structures.php, so if MySQL is not available on the machine where the documentation is written, this page can be printed or screenshotted instead — it shows exactly the columns, keys and relations that phpMyAdmin will display after the import.
